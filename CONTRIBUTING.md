# Contributing to ProdigyDownloader

Thank you for contributing to **ProdigyDownloader** by [ProdigyNova](https://www.prodigynova.com).

## How to contribute

1. Fork the repository and create a feature branch.
2. Build and test locally: `dotnet build` and `dotnet test`.
3. Keep changes focused; match existing code style.
4. Open a pull request against `main` with a clear description.

## Reporting bugs

Use [GitHub Issues](https://github.com/mitribox/ProdigyDownloader/issues) and include:

- Windows version
- ProdigyDownloader version
- Steps to reproduce
- Expected vs actual behavior
